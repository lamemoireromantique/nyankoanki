# にゃんこ暗記塾 iPad版

## 公開方法（GitHub Pages）
1. GitHubリポジトリの「Add file」→「Upload files」。
2. このフォルダ内の **index.html / kitten.png / icon.png / manifest.webmanifest / sw.js** をリポジトリ直下へアップロード（フォルダごとではなく中身）。
3. Commit changes。
4. Settings → Pages → Deploy from a branch → Branch: main / Folder: /(root) → Save。
5. 発行URLをiPadのSafariで開き、共有 → ホーム画面に追加。

## データについて
問題・正誤履歴・復習予定・猫のレベルはブラウザのlocalStorageに保存されます。
SafariのWebサイトデータ削除や端末故障に備え、アプリ内の「バックアップ」から定期的にJSONを書き出し、iCloud Drive等へ保管してください。
この版はiPad内保存で、自動同期はありません。別端末への同期には別途クラウドDB等の実装が必要です。

## 注意
これはGitHub Pagesで公開するWebアプリです。リポジトリがPublicの場合、ソースファイルは公開されます。学習データは公開リポジトリへ登録せず、アプリを開いた端末のブラウザ内に保存してください。


## 改修版のデータ保護・4択機能
- 問題登録時に正解と誤答の選択肢3つを登録し、出題時は4択で表示します。
- 回答をタップすると、その場で正誤と正解を表示します。解説を確認したあと、復習間隔の判定を記録します。
- 既存のschemaVersion 1データは、読み込み時に元データを `nyankoAnkiData_backup_before_v2` として退避してから、選択肢欄を追加したversion 2形式へ移行します。旧データの問題・履歴・学習記録は維持します。
- 未知のデータ形式や破損データを検出した場合は、空データで上書きしないよう保存を停止します。
- バックアップ復元の前には、現在のデータをlocalStorage内に自動退避します。定期的なJSON書き出しは引き続き必要です。
- 古い問題は4択の誤答選択肢が未登録です。「問題一覧」→「編集」で3つ追加してから出題してください。
- 猫は問題画面にも表示され、遊びの操作に合わせてCSSアニメーションで動きます。動画ファイルではありません。

※データは引き続き端末のSafari内に保存され、GitHubには送信されません。公開版へ反映する前に、必ずiPad上でJSONバックアップを手元に保管してください。
